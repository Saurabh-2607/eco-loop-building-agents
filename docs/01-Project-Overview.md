# EcoLoop Building Agents

## Overview

EcoLoop Building Agents is an AI-powered building optimization platform that continuously monitors an EnergyPlus simulation, analyzes the building's operational state using an open-source Large Language Model (LLM), and autonomously adjusts building control parameters to reduce energy consumption while maintaining occupant comfort.

The system creates a closed feedback loop between the building simulator and the AI agent, enabling real-time optimization of HVAC, lighting, and ventilation systems.

---

## Objectives

- Reduce overall building energy consumption
- Maintain occupant thermal comfort
- Optimize HVAC and lighting schedules
- Provide explainable AI-driven decisions
- Visualize building performance in real time

---

## Core Features
